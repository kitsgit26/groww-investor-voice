
# Groww Investor Voice

An independent AI-powered customer discovery prototype exploring
first-time mutual fund investor experiences.

## Features
- CSV feedback upload
- Rule-based thematic classification
- Optional AI classification
- Evidence quotation validation
- Human review workflow
- Theme frequency analysis
- CSV export

## Technology
- Python
- Streamlit
- Pandas
- OpenAI API

## Research integrity
The built-in sample records are illustrative practice data.
They are not verified Groww customer feedback or interviews.

## Safety
This application provides general educational research analysis,
not investment advice. It does not recommend mutual funds or stocks.

## Run locally
Install dependencies:

pip install -r requirements.txt

Run:

streamlit run app.py
